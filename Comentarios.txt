Codigos de creacion de esta madre

Para inicializar y clonar repositorio:
git init
git add .
git clone 
git commit -m "nombre commits"
git remote add origin https://github.com/FredyCoxaj/DesarrolloWeb.git
git branch -M main 
git push -u origin main 

Para subir archivos:
git add . 
git status
git commit -m "nombre commits"
git push origin main 
git push 

Para descargar archivos y clonar:
git clone https://github.com/FredyCoxaj/DesarrolloWeb.git
git pull
